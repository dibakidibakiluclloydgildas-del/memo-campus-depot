# MÉMO CAMPUS — fiche de test (à envoyer à votre ami)

**Version testée** : 0.1.0 · **Durée** : ~25 minutes · **Compte** : `etudiant@demo.memo-campus.cm` / `MemoCampus2026!` — ou bouton **« Entrer en mode démonstration (un clic) »**.

Merci de tester ! Ce que tu vois est une vraie application (Web + Android) connectée à une vraie base de données, pas une maquette.

⚠️ **Deux choses à savoir pour ne pas croire à un bug :**
1. Les résumés, cartes et épreuves sont produits en **mode démonstration** : ils sont construits à partir du **vrai texte de tes cours** (extraits réels, avec la page source), sans IA distante. C'est indiqué dans l'interface.
2. Les **paiements ne sont pas activés** (aucun compte marchand branché) : l'écran d'abonnement s'affiche, mais aucun débit n'a lieu.

## Parcours guidé — coche au fur et à mesure

### A. Entrer (2 min)
- [ ] J'ouvre le lien / l'application.
- [ ] Je me connecte (bouton démo ou identifiants).
- [ ] Le tableau de bord affiche des chiffres réels (cours, cartes à revoir, série de révision).

### B. Importer un cours (5 min)
- [ ] **Bibliothèque → Importer un cours** : j'envoie un PDF de mes cours (ou une photo).
- [ ] Le statut évolue : *En file → Extraction → (OCR) → Structure → Prêt*. Le temps d'analyse me paraît-il raisonnable ?
- [ ] Je vérifie que les chapitres détectés correspondent vraiment à mon document.
- [ ] (Si j'ai importé une photo) les passages douteux sont **signalés** au lieu d'être inventés.

### C. Lire l'analyse (4 min)
- [ ] **Générer le résumé** : le résumé est-il fidèle au cours ? Les notions essentielles ont-elles une **page source** ?
- [ ] La mention « mode démonstration » est-elle claire (compris ce qu'elle implique) ?
- [ ] J'ouvre la **fiche de révision** : lisible, imprimable, utile avant un contrôle ?

### D. Réviser (4 min)
- [ ] **Révisions → Démarrer la session** : je réponds de mémoire, puis j'affiche la réponse.
- [ ] Je note honnêtement (*Oublié / Difficile / Bien / Facile*) : la carte revient-elle plus tard quand je réussis ?
- [ ] Chaque carte indique **pourquoi** elle m'est proposée : est-ce compréhensible ?

### E. Être évalué (5 min)
- [ ] **Évaluations → Nouvelle épreuve** : QCM + une question écrite, 20 minutes.
- [ ] Pendant l'épreuve : chronomètre, navigation, sauvegarde automatique.
- [ ] Après soumission : note, détail par question, **explication et page du cours**, grille de la question ouverte.
- [ ] Les questions me semblent-elles pertinentes (pas piégeuses, pas hors sujet) ?

### F. S'organiser (3 min)
- [ ] **Planning** : je saisis mes disponibilités, puis **Proposer un planning**.
- [ ] Les séances respectent-elles mes horaires ? Chaque séance explique-t-elle **pourquoi** elle est là ?
- [ ] Je lance un **Pomodoro** de 25 min (ou j'écourte).

### G. Assistant (2 min)
- [ ] Je pose une question sur mon cours : la réponse **cite-t-elle une page** de mon document ?
- [ ] Je passe en **mode professeur** : il me pose **une seule question à la fois** ?

### H. Application Android (5 min, si APK ou Expo Go)
- [ ] L'application s'ouvre sur mon compte (mêmes cours que sur le Web).
- [ ] J'ouvre un cours → **Télécharger pour hors connexion**.
- [ ] Je passe en **mode avion** : le résumé et la fiche restent lisibles.
- [ ] Je lance une révision hors connexion : mes réponses sont **en attente de synchronisation**, puis envoyées au retour du réseau.
- [ ] L'application m'indique **clairement** que l'import, l'IA et la correction nécessitent Internet.
